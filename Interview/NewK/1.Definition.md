# Definition:

- Event-driven business system
- Online app (real-time)
- Workflow/orchestration
- Analytics & reporting

# Suppose

1. People using the system
   Tech: Blazor, .NET 8/9, Azure Entra/B2C, AWS/Azure
   “user uses website / app” part.

- Blazor: web FE
- Azure Entra: authentication, authorization
- .NET 9/0: BE
- AWS: Deploy APIs server, database

2. Messages between systems (background work)
   Tech: Apache Pulsar

- Apache Pulsar: (message bus) publisher and subscriber the message (one service send message to the queue, another service subscribe this queue to handle the logic)

3. Long business processes
   Tech: Camunda BPM
   “sales per month, top customers, fail rate, etc.”

- Camunda BPM: workflow engine that controls a full business process

4. Reports & dashboards
   Tech: SSIS, Data Warehouse, Power BI

- SSIS: runs jobs that copy the data between database (and maybe also from Pulsar logs) in the the Data Warehouse. Something like manage the ETL job
- Power BI: connects to the Data Warehouse and builds dashboards
  - SSIS = moves and cleans data.
  - Data Warehouse = central report database.
  - Power BI = charts and dashboards.

# One simple flow end-to-end

- User logs in (Azure Entra/B2C) → uses Blazor site.
- User creates order → .NET API saves order to DB.
- API sends “OrderCreated” message to Pulsar.
- Camunda starts “Order Process” and calls other services.
- At night, SSIS copies order data to Data Warehouse.
- Next day, Power BI shows yesterday’s sales.
